# Se connecter

Vous vous connectez avec les identifiants habituels de votre organisation (single sign-on) — OpenBastion ne vous demande pas de créer un mot de passe séparé.

*Limite connue du périmètre actuel* : il n'existe pas encore de portail web dédié aux opérateurs (prévu en v0.0.1). En attendant, vous demandez vos sessions via la ligne de commande ([Demander une session](requesting-access.md)) ou l'interface qui vous a été fournie par votre administrateur.
